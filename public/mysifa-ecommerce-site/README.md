# MySIFA E-Commerce Website

Website landing page responsif berdasarkan konsep poster MySIFA:
- MySIFA E-Commerce — Menjangkau Lebih Banyak Pelanggan
- Payment Gateway
- Pelanggan Get Pelanggan
- Program Diskon
- History Pengobatan
- 51 fitur MySIFA
- CTA WhatsApp

## Struktur
- `index.html` — halaman utama
- `css/style.css` — seluruh styling dan responsive layout
- `js/app.js` — menu mobile dan tahun footer
- `assets/mysifa-logo.jpg` — logo yang diekstrak dari poster
- `assets/poster-reference.png` — poster asli sebagai referensi

## Cara menjalankan
Tidak membutuhkan PHP atau database untuk versi landing page ini.
Cukup buka `index.html` di browser.

Untuk hosting:
1. Upload seluruh isi folder ke `public_html`.
2. Pastikan `index.html` berada di folder utama.
3. Ganti nomor WhatsApp di `index.html` jika diperlukan.

## Catatan
Versi ini sengaja dibuat HTML/CSS/JS murni agar mudah dipasang pada hosting biasa, Laravel Blade, atau PHP legacy.
